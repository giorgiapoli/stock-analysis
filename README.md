# Stock Analysis Dashboard

Web page to read and analyse the "Stock Analysis" file produced by a branch's Excel macro.

- Opens in the browser: `index.html`, no installation.
- Upload one or more `.xlsm` / `.xlsb` / `.xlsx` files: the branch and the month are recognised from the file.
- Summary, analysis to decide (lots at risk, excess stock, reorders, suppliers), item groups and mastercodes, item search.

## Privacy

Files are read **only in the user's browser**. They are not sent to any server. The archive of the uploaded months stays in the browser of whoever uses the page.
Excel files are read with the [SheetJS](https://sheetjs.com) library, loaded from the internet (cdnjs).

## Use

Open the page, drop the files generated by the macro and choose branch and month from the menu at the top.
